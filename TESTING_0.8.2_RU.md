# PROJECT GENESIS 0.8.2 — запуск Foundry v13

## Причина исправления

В версии 0.8.1 поле `industryJob` повторно использовалось в двух `ArrayField` (`industry.jobs` и `industry.construction`). Foundry v13 назначает каждому `DataField` только одного родителя; повторное использование вызывало ошибку при инициализации мира. Теперь каждое поле строится отдельной фабрикой.

## Установка вручную

1. Закройте Foundry и сделайте копию мира `Data/worlds/<ваш-мир>`.
2. Распакуйте `project-genesis-v0.8.2.zip` и замените папку `Data/systems/project-genesis` новой папкой `project-genesis`.
3. Запустите Foundry и войдите в тестовую копию мира.
4. Проверьте наличие рабочего интерфейса, открытие листа выжившего и колонии и вкладки «Строительство».
5. При следующей ошибке откройте F12 → Console и сохраните первую красную ошибку со стеком.

## Тесты

Запустить из исходников: `node --test tests/*.test.mjs`.
Node.js нужен только для тестирования; Foundry самостоятельно запускает клиентский код.

## GitHub

Обновите файлы в репозитории, убедитесь, что версия `system.json` стала `0.8.2`. Автоматический workflow создаст релиз `v0.8.2`.
