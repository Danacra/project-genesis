# PROJECT GENESIS 0.8.4 — вкладки и личный инвентарь

Сделайте резервную копию мира; установите полную сборку поверх прежней системы. НЕ удаляйте данные мира.

1. Откройте актёра «Колония». В шапке между названием и игровым днём должен быть выпадающий список «Раздел» и кнопка «Общий склад».
2. Поочерёдно выберите 10 разделов через выпадающий список. Должна быть видна только одна страница.
3. Проверьте переключение через горизонтальные вкладки. Выбор должен синхронизироваться в выпадающем списке.
4. Откройте актёра типа «Выживший» (survivor). На обзоре отображается блок «Личный инвентарь выжившего» с загрузкой, а в шапке — кнопка «Инвентарь».
5. Нажмите «Открыть инвентарь», затем «+ Добавить предмет» и проверьте отображение количества, массы и объёма.
6. Если кнопка неактивна у игрока, проверьте права Owner на актёра; у GM доступ есть.
7. При новом запуске лист должен открываться с обзора без показа двух страниц одновременно.

Ограничение: тесты Node.js и браузерный предпросмотр не заменяют полноценный запуск Foundry VTT v13.
