# PROJECT GENESIS 0.8.1 — ручная проверка в Foundry VTT v13

Проверка в **копии мира**, не в основном игровом мире. Перед обновлением сохраните папку системы и резервную копию мира. Это тестовая сборка; Node.js-проверки не подтверждают работу интерфейса в живом Foundry.

## Установка и совместимость

- [ ] Установите v0.8.1 поверх v0.8.0 в `Data/systems/project-genesis/`; проверьте версию в менеджере систем.
- [ ] Убедитесь, что сохранились: персонажи, технологии, месторождения, здания, кабели, трубы и активные задания.
- [ ] Запустите одну сессию GM + второй браузер/пользователь с правом OWNER на актора «Выживший».
- [ ] Убедитесь, что NPC не отображается в списке доступных выживших для работы.

## Новые регрессионные сценарии

- [ ] На общей карте разместите два токена одного выжившего — один далеко, другой рядом с месторождением. Добыча рядом должна быть разрешена.
- [ ] Отправьте первую партию в локальную мастерскую; затем другим выжившим попробуйте направить вторую, суммарно превышающую лимит мастерской. Вторая отправка должна быть отклонена ДО списания груза из инвентаря.
- [ ] Повторите сценарий для общего склада с почти заполненным инвентарём колонии.
- [ ] Выполните штатный перевод суток. Проверьте, что каждое активное задание уменьшается на 1 сутки, а завершённые задания не уходят в отрицательные значения.
- [ ] При повторном вызове `game.projectGenesis` не нужно вручную вызывать служебные функции. Проверка отказоустойчивости повторного расчёта суток сделана в автоматических тестах — не имитируйте аварийное сохранение в основном мире.
- [ ] Создайте два выживших с одинаковым именем. Задание одного должно помечать занятым только его, а не второго.
- [ ] Истощите месторождение, затем удалите его через GM. Убедитесь, что Tile исчез и запись не осталась в колонии.
- [ ] Если Foundry выдаёт ошибку при изменении сцены/мира, проверьте актуальность тайлов и журнал консоли. Не удаляйте вручную важные записи без резервной копии.

## Обязательная повторная проверка 0.8

Выполните сценарии из `TESTING_0.8_RU.md`: добыча, отмена, перемещение груза в здание, доставка в складской модуль, возврат из локального кэша, тележка, сохранение после перезагрузки и два клиента.

## Известные ограничения

- Транспортировка абстрактна и занимает игровые сутки, не двигает токены физически по сцене.
- Старая мгновенная передача предметов из 0.3 продолжает работать; строгая физическая логистика ещё не обязательна для всего производства.
- Нужна квадратная сетка. Нельзя моделировать движение через препятствия, стены, рельеф и этажи.
- Сбой общей операции `advanceDay` может частично сохранить изменения других подсистем; защиту от повторного списания 0.8.1 добавляет только для заданий экипажа.
- Интеграция на запущенном Foundry VTT v13 не была проверена автоматически. Если UI выдаёт ошибку, сохраните запись консоли (F12) и создайте копию мира перед повтором.
