# PROJECT GENESIS v0.8.5 — стабильность перехода суток и интерфейса

Исправлены пять замечаний аудита основного репозитория (данные мира не удаляются):

1. Переход суток сохраняет полный план `dayOperation` в world settings **до** списания и записывает абсолютные итоги по предметам, выжившим и очередям. Повтор операции не расходует припасы второй раз. После сбоя ведущий повторяет `+1 сутки` либо следующий запуск GM автоматически возобновляет операцию. Пока она не завершена, другие игровые команды блокируются.
2. Кнопка вложения очков теперь блокируется при отсутствии мастерской / лаборатории, электропитания, предыдущих исследований или свободных очков. Причина видна под кнопкой и в подсказке.
3. Фильтр технологий сбрасывает выбранную карточку на первую видимую; пустая выдача показывает сообщение.
4. В диалоге перемещения назначение подписано типом (общий склад / выживший / NPC GM), а чужой выживший поясняется как доступный только получатель.
5. Лист показывает реальную версию `game.system.version`, а не зашитый номер.

Содержит интерфейсные улучшения 0.8.3–0.8.4 для навигации и личного инвентаря. Для теста сделайте резервную копию мира.

Тесты: `node --test tests/*.test.mjs`; пакет: `python scripts/package_release.py`.
