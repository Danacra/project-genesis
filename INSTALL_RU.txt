PROJECT GENESIS 1.6.4 — ВРЕМЯ И ПЕРСОНАЖИ
=========================================
ОФЛАЙН-ПАТЧ ДЛЯ FOUNDRY VTT V13. Нужна установленная система 1.6.3.

1. Выключите Foundry VTT и сохраните резервную копию игрового мира.
2. Извлеките ВЕСЬ ZIP в отдельную папку.
3. Запустите apply_update.bat (требуется Python 3).
4. Укажите путь к установленной системе FoundryVTT/Data/systems/project-genesis.
5. Установщик проверит файлы, создаст резервную копию в соседней папке
   project-genesis-backup-before-164-<дата>.zip и заменит только системные файлы.
6. Перезапустите Foundry и браузер; проверьте версию и игровые часы.

Командная строка (без установки, только проверка):
  python apply_update.py --check "C:\\...\\FoundryVTT\\Data\\systems\\project-genesis"

ЧАСЫ
- Начало игрового времени: 08:00. Ведущий может поставить на паузу или выбрать
  скорость x1, x5, x10, x60 (в игровых минутах на реальную минуту).
- Часы идут, только пока подключён активный ведущий; остановленный мир не
  догоняет прошедшие реальные часы после перезапуска.
- «+1 ч» вручную сдвигает часы. «+1 день» остаётся как ручной переход суток.
- Еда/вода/погода/очереди продолжают рассчитываться один раз в полночь.
- Если переход суток завершился с ошибкой, время автоматически ставится на паузу,
  а мастер может восстановить переход через «+1 день» после исправления причины.

СПЕЦИАЛИЗАЦИИ
- Медик, Инженер, Учёный, Мастер, Разведчик, Выживальщик.
- Порог: нужная характеристика 6+ и соответствующий навык 4+.
- Нет новых механических бонусов; указаны только будущие эффекты.
- Данные старого поля специализации сохранены, но интерфейс показывает расчёт.
