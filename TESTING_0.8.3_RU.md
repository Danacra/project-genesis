# PROJECT GENESIS 0.8.3 — исправление вкладок

Проблема: в листе колонии Foundry v13 на некоторых клиентах отображается дерево технологий сразу под шапкой, но пропадает панель переходов.

Исправление: `<nav>` заменён на отдельный `<div role="tablist">` с теми же десятью кнопками; CSS принудительно делает панель видимой и позволяет горизонтальную прокрутку.

## Проверка

1. Создайте резервную копию мира.
2. Остановите Foundry; замените `Data/systems/project-genesis` папкой из полного ZIP.
3. Запустите тестовый мир Foundry v13 и откройте лист актора типа `Колония`.
4. Проверьте наличие меню «Обзор», «Инвентарь», «Контейнеры», «Исследования», «Чертежи», «Производство», «Строительство», «Энергия и сети», «Экипаж и логистика», «Журнал операций».
5. Нажмите каждую вкладку; только выбранная страница должна отображаться, активная вкладка выделяется.
6. При уменьшении ширины прокручивайте навигацию горизонтально.

Внимание: изменение проверено статическими тестами и тестами Node.js; работа в реальном Foundry v13 должна быть проверена пользователем.
