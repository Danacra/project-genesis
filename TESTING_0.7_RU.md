# Ручная проверка PROJECT GENESIS 0.7 в Foundry VTT v13

## Перед началом

1. Создайте резервную копию мира, используйте тестовую сцену и тестовую колонию.
2. Проверьте, что прежние персонажи, инвентарь, дерево технологий, производство и 12 зданий сохранились после обновления.
3. Откройте локальную сцену с квадратной сеткой 100 px.
4. С помощью GM разместите 3 готовых здания с небольшими проходами между ними: «Энергетическая станция», «Лаборатория электроники», «Станция воды». При необходимости используйте существующие здания v0.5 через кнопку «Отметить готовое на карте».
5. Положите на общий склад 20 меди (код `copper`) и 20 сплава (код `alloy`).

## Функциональная проверка

- [ ] Откройте вкладку **Энергия и сети**, убедитесь, что видны списки зданий, энерго- и водобаланс.
- [ ] До прокладки электрической линии лаборатория электроники отображается без питания.
- [ ] Выберите электрический кабель между энергостанцией и лабораторией. Два разных здания должны находиться на одной сцене.
- [ ] GM подтверждает запрос, медь списывается согласно длине маршрута, на карте появляются тайлы кабеля с подходящими поворотами.
- [ ] Лаборатория получает питание. Если нужные исследования и другие материалы доступны, лаборатория может запускать соответствующие производственные задания.
- [ ] Попробуйте повторить такую же линию — дублирование должно быть отклонено без второго расхода.
- [ ] Соедините кабелем энергостанцию и станцию воды, убедитесь, что она запитана, а водная инфраструктура получает 12 условных единиц предложения.
- [ ] При наличии теплицы или жилого модуля подключите станцию воды трубой и проверьте их состояние. При прокладке должна тратиться **сплав**, не медь.
- [ ] Добавьте блокирующую постройку между двумя зданиями — маршрут должен обойти её; при полностью занятых проходах действие должно завершиться отказом без списания.
- [ ] Откройте Foundry вторым пользователем (не GM), владельцем выжившего. Отправьте запрос прокладки и проверьте результат у GM и на карте.
- [ ] GM удаляет один **сегмент кабеля** через стандартный инструмент Tiles; сеть должна стать неисправной, а питание зависимого здания пропасть.
- [ ] GM нажимает **Восстановить тайлы**; линия восстанавливается в прежних координатах без повторной оплаты материалов.
- [ ] GM демонтирует исправную сеть; удаляются её тайлы, доступность потребителей пересчитывается. Материалы при демонтаже **не возвращаются**.
- [ ] Перезапустите мир и проверьте сохранение оставшихся линий, состояния помещений и статусов.
- [ ] Проверьте обычную работу раннего верстака без электрической сети — производство должно оставаться доступным в ручном режиме.

## Ошибки и ограничения

Не перемещайте тайлы инженерных сетей вручную, кроме проверки диагностики. В v0.7 программно учитываются клетки и здания PROJECT GENESIS; стены, высота, другие декоративные Tiles и проходимость сцены **не анализируются**. При серьёзной ошибке восстановления используйте резервную копию.
