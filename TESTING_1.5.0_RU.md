# PROJECT GENESIS v1.5.0 — проверка после установки

## Обязательно: резервная копия

Перед установкой сделайте backup Foundry `Data/worlds/<world>` и установите полную систему `project-genesis` вместо предыдущей версии. Не удаляйте данные мира. Старые placement без `tier` считаются уровнем I.

## 1. Технологии и рецепты

- В листе колонии изучите «Обработка древесины», «Ткачество и волокна», «Обжиг материалов», «Переплавка руды».
- Убедитесь, что до открытия технологии неизвестный чертёж игроку не показывается; GM видит его статус.
- Для досок требуется `wood ×2`; верстак производит `plank ×3`.
- Для ткани требуется `fiber ×3`; верстак производит `cloth ×2`.
- Для металлических слитков требуется `ore ×3`; промышленная мастерская производит `ingot ×2`.
- Для кирпича требуется `clay ×3`; промышленная мастерская производит `brick ×3`.

## 2. Прогресс построек

- Постройте два верстака. У первого нажмите «Улучшить до 2» (после исследования и за ресурсы), у второго не меняйте уровень.
- Проверьте, что на карте первый верстак изменил иконку на уровень II; второй остался I.
- На верстаке II доступен рецепт «Точный набор соединений», на I — нет.
- После уровня III появляется «Калиброванный инструмент».
- Улучшите локальный склад: вместимость I = 750 кг / 1500 л, II = 1275 кг / 2550 л, III = 1875 кг / 3750 л.
- Проверяйте жилой модуль в реальном мире: отдых на II–III уровнях лучше. Генератор II–III уровня повышает мощность в сети.
- GM может бесплатно повышать уровень через кнопку «GM бесплатно». Обычный игрок не может воспользоваться этим режимом.

## 3. Новый рабочий стол

- Кликните на готовый верстак на сцене. Откроется окно с левой колонкой «Источник материалов» и рабочим столом.
- Выберите личный инвентарь, общий или локальный склад.
- Перенесите нужные ингредиенты на стол, либо нажимайте «+» / «Все».
- Кнопка «Скрафтить» должна активироваться только при точном количестве всех компонентов.
- До нажатия на кнопку реальные материалы не списываются.
- При нажатии дождитесь подтверждения ведущего и анимации. Продукция появляется в выбранном источнике, затраченные материалы исчезают.
- Проверьте отказ при нехватке материалов, переполнении инвентаря, отключении питания и при выборе чужого выжившего.
- Для обычного игрока токен его выжившего должен находиться рядом со станком на соответствующей сцене.

## Ограничения

Новый быстрый крафт из GUI берёт материалы из одного выбранного источника за операцию. Смешивание ингредиентов из разных хранилищ в одной операции пока не поддерживается. Обычная очередь производства по игровым суткам сохранена в меню колонии.

Автоматические тесты проверяют планирование и сохранение, но не гарантируют работу каждого клика в живом Foundry. Для окончательного выпуска протестируйте с аккаунтом GM и отдельным игроком в реальном клиенте Foundry VTT v13.
